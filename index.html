GitHub Goldfish

A pet app by Astra. A goldfish swims through every public word on a GitHub account and tells you what is wrong, misplaced, or inconsistent.

Ready. Press Release the goldfish. mood: happy

Public repos only. Goldfish reads what any visitor can read.

Only raises the rate limit (60 to 5,000 requests an hour). Held in memory, sent only to api.github.com, never saved. Needs no scopes.

Saved in this browser only, never in the repo. Add your employer's name here: no work information in public repos.

What the goldfish found

What the goldfish could not see

    Checks: Document control (missing or malformed required files, pet files, headings, stray copies and secrets files), Blatant (typos, doubled words, mojibake, placeholders, secrets, broken links and anchors, brand spellings, never-say words), Organizational (names, topics, homepage, stubs, profile list), Systemic (patterns across the whole account: license, apostrophes, dashes, description style, the Cage registry).

    Not checked: spelling beyond a short typo list and doubled words, external links (browsers cannot test them), issues, pull requests, wikis, releases, gists, commit messages, text inside images, private repos, the contents of live websites.
