Without a token Goldfish reads public repos only. With a token for this account it reads private repos too.

(?) What is thisA GitHub token is a revocable access credential. Public audits work without it, subject to rate limits. Private audits need access to the selected repositories. Use the least access needed. This page keeps it in memory and sends it only to api.github.com. Never paste it into chat.

Raises the rate limit (60 to 5,000 requests an hour) and, if it belongs to this account, opens private repos. Classic token: repo scope. Fine-grained: only the repositories you intend to audit, Contents read-only. Held in memory, sent only to api.github.com, never saved.

    What the goldfish could not see

      Checks: Document control (missing or malformed required files, pet files, headings, stray copies and secrets files), Blatant (typos, doubled words, mojibake, placeholders, secrets, broken links and anchors, brand spellings, never-say words), Organizational (names, topics, homepage, stubs, profile list, old pet words from the Cage's PET-WORDS.md), Systemic (patterns across the whole account: license, apostrophes, dashes, description style, the PetOS registry).

      Not checked: spelling beyond a short typo list and doubled words, external links (browsers cannot test them), issues, pull requests, wikis, releases, gists, commit messages, text inside images, private repos when no token for the account is given, organizations' private repos, the contents of live websites.
